## ⚡ Stack Tecnológica & Performance

- **Frontend Core:** HTML5 Semântico, Tailwind CSS (Design Tokens Customizados), GSAP 3 + ScrollTrigger.
- **Tipografia:** Anton (Display Brutalista) & Montserrat (Body de Alta Legibilidade).
- **SEO & Web Standards:** Schema.org JSON-LD estruturado, Open Graph, Twitter Cards, \obots.txt\, \sitemap.xml\, \llms.txt\ para AI Search Engines (AEO/GEO).
- **Acessibilidade:** WCAG 2.1 Níveis AA/AAA com contrastes calibrados, focus states e suporte a leitores de tela (\ria-label\).
- **DevOps & QA:** Suíte de testes automatizados com Playwright para Desktop (1440x900) e Mobile (390x844).
